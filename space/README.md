# Object Detection · Deformable DETR + traducción de etiquetas

Detecta los objetos de una imagen con **Deformable DETR** y traduce sus etiquetas al español con **Helsinki-NLP**. Los modelos se ejecutan dentro de este Space con `transformers` (CPU), así que no hace falta token ni créditos de inferencia.
